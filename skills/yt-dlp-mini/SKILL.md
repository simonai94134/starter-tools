# yt-dlp-mini — 把影片變成你的知識

## 這個 skill 在做什麼

不是幫你「摘要影片」。摘要看完就忘了。

這個 skill 做的是**一條完整的迴路**：抓下影片內容 → 用**你的**背景去判斷哪些對你有用 → 存進你的第二大腦 → **反問你一題**，確認你真的吸收了才存檔。

存進去的每一張知識卡，下次遇到相關的事會被翻出來，跟新東西產生連結。這就是它會越來越懂你的原因。

---

## 執行步驟

### Step 1 · 抓字幕

先確認使用者給了 YouTube 網址。沒有就問：「把影片網址貼給我。」

在使用者的工作資料夾底下執行（`URL` 換成實際網址）：

```bash
yt-dlp --write-subs --write-auto-subs \
  --sub-langs "zh-Hant,zh-Hans,zh-TW,zh,en" \
  --skip-download --convert-subs srt \
  -o "%(title)s.%(ext)s" "URL"
```

**🔴 執行後一定要跟使用者說這句**（否則他會被畫面嚇到）：

> 「畫面可能會冒出紅色的 WARNING，也可能一行都沒有，兩種都正常，不用理它。**只看有沒有跑出一個 `.srt` 檔**，有就是成功了。」

**為什麼會有紅字**：YouTube 會擋自動化工具，yt-dlp 抓不到影片本體的部分會警告。但**字幕不受影響**，我們只要字幕。

> ⚠️ 給 AI：**不要用紅字的多寡判斷成敗，只看 `.srt` 檔在不在。** yt-dlp 一直在更新，同一支影片不同版本噴的紅字數量差很多。

**如果真的沒有產出 `.srt` 檔**，先看有哪些字幕可以抓：

```bash
yt-dlp --list-subs "URL"
```

有別的語言 → 換掉 `--sub-langs` 重跑。

#### 撞到 `429 Too Many Requests`

YouTube 限流，通常是短時間對同一支影片抓太多次（**多人同時抓同一支特別容易觸發**）。

處理：**換一支影片馬上就好**，或等幾分鐘再試。跟他說一句「這是 YouTube 擋的，不是你的網路有問題」，不要讓他以為自己弄壞了。

**完全沒有字幕** → 走下面的 Step 1b。**🔴 不要叫他換一支。** 他要的就是這一支，叫他自己再去找是最惱人的回答。

---

### Step 1b · 沒字幕：你自己把它轉出來

**先講一句讓他安心**：

> 「這支沒有字幕，不過沒關係，我直接把它的聲音轉成文字，一樣可以做。要花大概兩三分鐘。」

然後照順序做，**每一步都比下一步便宜，能停在前面就別往後**：

#### ① 看工具在不在

```bash
which whisper-cli ffmpeg
```

**兩個都有** → 跳到 ③，不要問他任何問題，直接做。

#### ② 缺工具才裝（要先問他）

**Mac**：

```bash
brew install whisper-cpp ffmpeg
mkdir -p ~/.cache/whisper-models
curl -L -o ~/.cache/whisper-models/ggml-base.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin
```

模型 `base` 約 **141MB**，一分鐘內載完。中文想更準可以換 `ggml-small.bin`（約 465MB），把網址和檔名的 `base` 換成 `small` 就好。

**問他這一句再動手**：

> 「要先裝一個轉錄工具，大概下載 150MB，一分鐘左右。**如果你現在在上課、旁邊很多人共用網路，先跟我說**，我們可以晚點再弄。要現在裝嗎？」

**Windows**：`brew` 不能用。自己想辦法（winget、或裝 Python 版的 whisper 都行），**能裝就裝**。真的裝不起來，這時候才退回「幫他找一支有字幕的」，並老實跟他說是工具裝不起來，不是他做錯。

#### ③ 只抽音訊（🔴 不要下載影片本體）

```bash
yt-dlp -x --audio-format mp3 --audio-quality 5 -o "audio.%(ext)s" "URL"
```

一支 13 分鐘的影片抽出來大約 **11MB**（影片本體會是 200MB 以上）。**而且音訊比影片不容易被擋。**

#### ④ 轉成 whisper 吃的格式

```bash
ffmpeg -y -loglevel error -i audio.mp3 -ar 16000 -ac 1 -c:a pcm_s16le audio.wav
```

#### ⑤ 🔴 送進去之前先驗音量（這一步不能省）

```bash
ffmpeg -hide_banner -i audio.wav -af volumedetect -f null - 2>&1 | grep mean_volume
```

- **正常人聲**：大約 −15 到 −30 dB → 繼續
- **低於 −40 dB**：這是無聲或幾乎無聲的影片（例如沒旁白的螢幕錄影）。**停下來**，跟他說「這支影片沒有人在講話，轉不出東西，我幫你找一支有講解的」。

> 🔴 **為什麼一定要驗**：whisper 遇到無聲不會回空白，**它會編**。實際發生過的案例是整份逐字稿變成「请不吝点赞 订阅 转发」這種重複的垃圾。**那種東西存進知識庫比沒存更糟。**

#### ⑥ 轉錄

```bash
whisper-cli -m ~/.cache/whisper-models/ggml-base.bin -f audio.wav -l auto -otxt -of transcript
```

速度參考：**音檔每 1 分鐘大約跑 10 秒**，13 分鐘的影片約 2 到 3 分鐘。跑的時候跟他說一聲「在轉了，大概兩三分鐘」，不要讓他盯著空畫面。

#### ⑦ 接回主流程

把 `transcript.txt` 當成字幕檔用，直接回到 **Step 2** 往下做。

**⚠️ 兩件事要處理**：
- **whisper 常常輸出簡體中文。** 寫知識卡的時候轉成繁體。
- **轉錄會有同音錯字**，專有名詞、數字、人名不確定的要標出來讓他確認，不要當成事實寫進知識卡。

#### ⑧ 收尾清乾淨

```bash
trash audio.mp3 audio.wav transcript.txt
```

沒有 `trash` 指令的機器就留著，不要用 `rm`。

### Step 2 · 讀進來

`Read` 那個 `.srt` 檔。字幕檔會有時間碼和重複行，讀的時候自動忽略，只看內容。

### Step 3 · 提煉（重點在這裡）

先讀使用者的地基規則，搞清楚他是誰、在做什麼、最頭痛什麼。**兩個位置都找一下**（Codex 是 `AGENTS.md`，內容通常指向或就是 `000_Agent/CORE_RULES.md`）：

```
AGENTS.md
000_Agent/CORE_RULES.md
```

兩個都找不到 → 跟他說：「我還不認識你，這樣提煉出來的東西會很空。要不要先跑一次『建你的 AI 大腦』？」他堅持先做，就先問他三句：你在做什麼、最近在煩什麼、這支影片你想解決什麼。

**然後不要做摘要。做這四件事：**

1. **這支影片在講什麼** — 三句話以內
2. **哪幾點對「他」有用** — 扣著他的生意講，不是泛泛而談。他開餐廳，就講這對餐廳能怎麼用
3. **哪幾點對他沒用 / 不適用** — 這點很重要，講清楚為什麼不適用（例如：這是美國市場的做法，馬來西亞的客群結構不一樣）
4. **他可以馬上做的一件事** — 具體到可以今天就動手

⚠️ 影片裡沒講的東西不要自己補。你不確定的地方直接說「這支影片沒講到 X，如果你要做這件事還缺這塊」。

### Step 4 · 🔴 反問（不可略過）

**先不要存檔。** 用影片裡的內容問使用者一題，確認他真的看懂了：

> 「存進去之前先問你一題：〔用影片裡的一個關鍵點出題〕，你會怎麼用在你的店？」

- 答得出來 → 進 Step 5
- 答不出來、或說「我沒時間看」 → **不要為難他**。換個方式：「那我用最白話再講一次這支在講什麼，你聽完再說。」講完再問一次。
- 他答的東西比影片講的更好 → **把他的答案一起寫進知識卡**，那是他的經驗，比影片值錢。

**為什麼要這一步**：只是存檔的東西，跟按「收藏」沒兩樣，永遠不會再打開。答過一次才會變成他自己的。

### Step 5 · 存進第二大腦

寫成一張知識卡，存到他的知識庫資料夾（找不到就問他放哪）。檔名用 `YYYY-MM-DD_主題.md`。

```markdown
# [主題]

> 來源：[影片標題]（YouTube）
> 存入：YYYY-MM-DD

## 講了什麼
[三句以內]

## 對我有用的
- [扣著他的生意]

## 不適用的
- [為什麼]

## 馬上可以做的一件事
[具體行動]

## 我的想法
[Step 4 他自己答的，如果有]
```

寫完跟他說：**「存好了。下次你問我相關的事，我會把這張翻出來。」**

### Step 6 · 收尾

清掉那個 `.srt` 檔（原始字幕檔沒有保留價值，知識卡才有）：

```bash
trash "檔名.srt"
```

沒有 `trash` 指令的機器就留著，不要用 `rm`。

## 邊界

- **優先用字幕，沒字幕才轉錄**（Step 1b）。**永遠只抽音訊，不下載影片本體。**
- 轉錄前一定驗音量。無聲影片會讓 whisper 產生幻覺，幻覺逐字稿**不准進知識庫**。
- 抓自己有版權或公開授權的內容沒問題。**別拿去下載別人的完整影片轉賣或重傳。**
- 字幕是機器聽打的，會有錯字和斷句問題。**專有名詞、數字、人名不確定的，標出來讓使用者確認，不要當成事實寫進知識卡。**
