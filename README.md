> 這包是公開的，誰都能下載。裡面是一些不綁特定生意、任何人都用得上的小工具。

## 怎麼拿

**方法一（最簡單）**：點這頁上面綠色的 **Code** 按鈕 → **Download ZIP** → 解壓縮。

**方法二**：如果你已經會用 git：

```bash
git clone https://github.com/simonai94134/starter-tools.git
```

## 裡面有什麼

### `skills/yt-dlp-mini/` — 把影片變成你的知識

丟一支 YouTube 網址給它，它會：

1. 抓下字幕
2. 用**你的**背景判斷哪幾點對你有用、哪幾點不適用
3. **反問你一題**，確認你真的看懂了
4. 才存進你的知識庫

不是幫你做摘要。摘要看完就忘，這個是要變成你自己的東西。

**怎麼裝**：把 `yt-dlp-mini` 整個資料夾複製到你的 skills 資料夾（Claude Code 是 `~/.claude/skills/`，Codex 是 `.agents/skills/`）。

**要先裝 yt-dlp**：看 `setup/` 資料夾。

### `install-list.md` — 好用的 skill 去哪裡拿

一些別人做的好東西，附上原作者的位置。**自己去裝**，不要從來路不明的地方下載。

### `setup/` — 電腦要先準備的東西

yt-dlp 和 ffmpeg 的安裝方式。看不懂沒關係，裡面有教你怎麼叫你的 AI 幫你裝。

## ⚠️ 安全提醒（請認真看）

網路上有很多「skill 目錄站」，看起來很正規，其實沒有任何審核。有資安公司掃過其中一個市集的 3,984 個 skill，**超過三分之一有安全問題，抓到 1,467 個惡意程式**，會偷你瀏覽器裡存的密碼。

**skill 一旦被 AI 讀取，就有讀你檔案、跑指令的權限。** 你肉眼看不出裡面藏了什麼。

所以：

- ✅ 只從**官方**（anthropic 的 repo）或**原作者本人**的 GitHub 拿
- ✅ 看一下那個 repo 有多少人用（star 數）、最近還有沒有在更新
- ❌ 不要在 Google 搜「免費 skill 下載」然後隨便點
- ❌ 不要裝你不知道誰做的東西

不確定的，丟進群組問一聲，花三十秒總比中招好。
