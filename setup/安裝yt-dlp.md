# 安裝 yt-dlp（抓影片字幕用）

> `yt-dlp-mini` 這個 skill 要能跑，你的電腦要先有兩個小工具：**yt-dlp** 和 **ffmpeg**。
>
> 兩個都是免費的，裝一次就好。

---

## 最簡單的方法：叫你的 AI 幫你裝

**打開 Claude Code 或 Codex，把下面這句貼進去：**

> 「幫我在這台電腦上安裝 yt-dlp 和 ffmpeg。我不熟電腦，請一步一步帶我，需要我做什麼就直接跟我說。」

它會判斷你是 Mac 還是 Windows，自己處理該處理的。有需要你確認的地方它會問你。

**這就是這套系統的用法**：你不需要知道指令長什麼樣，你只需要講清楚你要什麼。

---

## 想自己裝的話

### Mac

先確認有沒有 Homebrew（Mac 上裝東西的工具）。打開「終端機」，貼這行：

```bash
brew --version
```

- 有跑出版本號 → 直接跳下一步
- 說「command not found」 → 先去 https://brew.sh 照著裝 Homebrew

然後裝兩個工具：

```bash
brew install yt-dlp ffmpeg
```

### Windows

打開「終端機」或「命令提示字元」，貼這兩行：

```
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

裝完**把終端機關掉重開**，不然它找不到剛裝好的東西。

---

## 確認裝好了

貼這行進去：

```bash
yt-dlp --version
```

有跑出一串日期樣子的版本號（例如 `2026.07.04`）就是成功了。

---

## 🔴 用的時候會看到一堆紅字，那是正常的

第一次抓字幕，畫面上會噴出一堆紅色的 `WARNING`，寫著什麼 `Signature solving failed`、`challenge solving failed` 之類的。

**不用理它，那不是你做錯。**

YouTube 會擋自動化工具，所以抓「影片本體」會失敗。但**我們只要字幕，字幕不受影響**。

**判斷成功的方式只有一個：資料夾裡有沒有跑出一個 `.srt` 檔。** 有就是成功了，紅字全部無視。

---

## 真的抓不到字幕的時候

先看看那支影片到底有沒有字幕：

```bash
yt-dlp --list-subs "影片網址"
```

- 有列出東西 → 挑一個語言代碼，跟你的 AI 說「用這個語言代碼再抓一次」
- 完全空的 → **這支影片沒有字幕，換一支就好**。不要花時間去下載影片轉語音，今天用不到那個。
